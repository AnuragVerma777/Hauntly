# Hauntly product context

Hauntly is a React and TypeScript social messaging application. Its user-facing experience includes account authentication, profiles, direct and group chat, friend discovery, location sharing, and an interactive globe for exploring locations. The deployed application and feature descriptions are documented in the root README.

## Product constraints

- Preserve the existing routes, authentication flow, chat behavior, globe experience, and offline fallback when changing application code.
- Keep changes aligned with the existing dark, supernatural visual identity and responsive interface.
- Treat live messaging, friend/location workflows, and globe interactions as existing product features; do not replace them with mock-only flows.
- Keep project documentation consistent with the currently implemented behavior. Distinguish planned work from shipped functionality.
